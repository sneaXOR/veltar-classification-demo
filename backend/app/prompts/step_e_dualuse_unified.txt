MÉTHODOLOGIE — 5 ÉTAPES SÉQUENTIELLES
═══════════════════════════════════════════════════════════════

ÉTAPE 1 — ANALYSE CATÉGORIELLE
Analyse CHAQUE catégorie (0-9) et justifie son inclusion ou exclusion.
Le tangible peut relever de PLUSIEURS catégories.
Exclusions connues :
- Cat 9 : moteurs/aéronefs certifiés EASA/FAA pour usage civil → généralement exclus
- Cat 0 : strictement nucléaire

ÉTAPE 2 — IDENTIFICATION DES ECCN CANDIDATS
Dans les catégories retenues, recherche les rubriques dont la définition correspond au tangible.
Raisonne sémantiquement : "drone" = "UAV" = "unmanned aerial vehicle", "outillage SPF" = "tools/dies for superplastic forming".
Pour chaque ECCN candidat, vérifie :
- La définition correspond-elle au tangible ?
- Les seuils techniques sont-ils satisfaits (si la rubrique en contient) ?
- Les notes/exclusions/conditions spécifiques s'appliquent-elles ?
  Exemple : 1B115 concerne uniquement les propergols, pas tout emboutissage.

ÉTAPE 3 — CROISEMENT NATURE E
Pour chaque ECCN confirmé du tangible, vérifie s'il est référencé dans une entrée Nature E de sa catégorie.
Attention : les entrées Nature E utilisent souvent des références par SECTION (ex: "1B" couvre tous les 1Bxxx).
Si l'ECCN du tangible est couvert par une entrée Nature E → le document PEUT être contrôlé.
Si aucune entrée Nature E ne le couvre → le document n'est PAS contrôlé même si le tangible est listé.

ÉTAPE 4 — QUALIFICATION TECHNIQUE DU DOCUMENT
Si une entrée Nature E applicable existe, détermine :
a) Le type de technologie du document :
   - Développement : conception, design, simulation, exigences, qualification
   - Production : fabrication, assemblage, outillage, procédés, test de production
   - Utilisation : opération, installation, maintenance, réparation, overhaul
b) L'entrée Nature E couvre-t-elle ce type de technologie ?
c) Le test fondamental : "Les éléments de ce document, à eux seuls, permettent-ils à un ingénieur de développer, produire ou utiliser le bien identifié ?"
   Chercher : paramètres de conception, procédures de fabrication, données de performance, instructions d'utilisation, procédures de test, code/algorithmes, schémas cotés.
   L'analyse de fond est PRIMAIRE. Le titre/auteur/type de document ne sont qu'un complément.

ÉTAPE 5 — EXCLUSIONS GTN
Les contrôles NE s'appliquent PAS à :
1. La technologie minimale nécessaire pour installation/maintenance/réparation de biens NON contrôlés
2. La technologie du domaine public
3. La recherche scientifique fondamentale
4. L'information minimale pour les demandes de brevets
