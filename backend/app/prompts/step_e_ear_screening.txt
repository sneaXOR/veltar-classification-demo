## METHODOLOGIE

Cette etape est un SCREENING : tu evalues les 10 categories (0-9) de la CCL pour
identifier les 1-3 categories les plus pertinentes pour l'item tangible.

1. **Identifier l'item** : Quel commodity, component, software, ou technology est
   decrit dans ce document ?

2. **Scanner les 10 categories** : Pour chaque categorie (0-9), evaluer si elle
   pourrait contenir un ECCN applicable :
   - Cat 0: Nuclear, firearms, ammunition
   - Cat 1: Special materials, chemicals, microorganisms
   - Cat 2: Materials processing (machine tools, equipment)
   - Cat 3: Electronics (semiconductors, circuits)
   - Cat 4: Computers
   - Cat 5: Telecommunications, information security
   - Cat 6: Sensors, lasers, cameras
   - Cat 7: Navigation, avionics
   - Cat 8: Marine
   - Cat 9: Aerospace, propulsion

3. **Identifier les groupes** : Pour chaque categorie retenue, preciser les
   groupes applicables (A=Equipment, B=Test/Production, C=Materials, D=Software, E=Technology)

4. **Lister les ECCN candidats** : Indiquer les ECCNs specifiques qui pourraient s'appliquer
   en se basant sur le sommaire SSTN fourni

5. **Decision rapide** :
   - Si AUCUN ECCN ne semble applicable -> EAR99 (pas de screening detaille necessaire)
   - Si des ECCNs candidats sont identifies -> indiquer les categories pour analyse detaillee

## REGLES

- NE PAS faire l'analyse detaillee ici (pas de verification de seuils techniques)
- Inclure les 600-series (ex: 9A610, 0A606) dans le screening
- Le General Technology Note (GTN) s'applique : si l'item tangible est controle,
  la technologie associee l'est aussi
- Le General Software Note (GSN) exclut les logiciels mass-market / domaine public
- Si l'item est clairement general purpose / commercial -> EAR99
- En cas de doute, retenir la categorie pour analyse detaillee (pas de faux negatifs)
